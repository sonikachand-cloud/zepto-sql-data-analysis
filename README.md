# Zepto Grocery Inventory & Pricing Analysis

A SQL project cleaning and analyzing a 3,700+ SKU grocery dataset to answer real business questions around discounting, stock availability, inventory value, and category performance.

## Overview

This project takes a raw, messy product dataset from a quick-commerce grocery platform and works through the full analyst workflow: creating the schema, validating and cleaning the data, calculating core KPIs, and writing business-focused SQL queries to surface actionable insights.

## Tools Used

- PostgreSQL
- SQL (aggregations, `CASE` logic, `GROUP BY` / `HAVING`, filtering, sorting)

## What This Project Covers

**Schema Design**
- The raw exported data had no unique product identifier, so `sku_id` was defined as a `SERIAL PRIMARY KEY` in the table schema — auto-generated by PostgreSQL on insert rather than sourced from the original file — to give every record a reliable key for joins, filtering, and lookups.

**Data Validation & Cleaning**
- Checked row counts and null values across every column
- Identified and removed a record with an invalid price
- Converted prices from paise to rupees
- Checked for invalid discounts and selling prices greater than MRP
- Nulled out corrupted/zero weight values instead of leaving bad data in place

**KPIs Calculated**
- Average discount percentage across all products
- Average selling price
- Total inventory value at current selling price
- Total inventory weight (in-stock only)

**Business Analysis (10 SQL Queries)**
- Top 10 products by discount percentage
- High-MRP products currently out of stock
- Estimated inventory value by category
- Products with MRP > ₹500 but discount below 10%
- Lowest price-per-gram products (value-for-money ranking)
- Average discount percentage by category
- Categories with average discount above 10%
- Overall in-stock percentage of the assortment
- Categories with the highest number of unique products
- Top 10 products by estimated inventory value

## Key Insights

- **Strong overall availability**: Of 3,731 product records, 3,278 were in stock — an **87.86% in-stock rate** overall, with the remaining SKUs representing a clear opportunity for inventory follow-up.
- **Fruits & Vegetables lead on discounting**: This category carries the highest average discount at **15.46%**, followed by Meats, Fish & Eggs at **11.03%** — suggesting these categories see the heaviest promotional activity.
- **High-value inventory is concentrated in a few SKUs**: Borges Extra Light Olive Oil holds the highest inventory value at **₹8,394**, followed by Praakritik Natural Desi Gir Cow A2 Ghee (**₹7,830**) and Saffola Gold (**₹7,440**) — these products warrant closer inventory monitoring given their outsized value per SKU.
- **Cooking Essentials and Munchies have the broadest assortment**: Both categories carry **478 unique products each**, the largest of any category — meaning inventory planning decisions here have the widest operational impact.
- **Some products carry very high individual discounts**: Items like Dukes Waffy Chocolate, Orange, and Strawberry Wafers are discounted at **51%**, with several others near **50%** — useful for promotional strategy targeting price-sensitive customers, though profitability on these SKUs should be tracked.
